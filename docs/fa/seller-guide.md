# راهنمای فروشنده (Seller)

## ورود

`/seller/login`

## وظایف

- ایجاد اکانت VPN برای مشتری
- درخواست شارژ از نماینده (کارت به کارت)
- تمدید / غیرفعال‌سازی اکانت
- مشاهده تراکنش‌ها و فاکتورها
- فروشگاه شخصی (`/seller/storefront`)

## ایجاد اکانت

1. بسته و سرور را انتخاب کنید
2. سیستم کمیسیون را از کیف پول کسر می‌کند
3. اکانت روی MikroTik/Sanaei ساخته می‌شود
4. لینک پورتال مشتری: `/portal/{token}`

## شارژ

فروشنده فقط از طریق Agent شارژ می‌شود (v1).

## پورتال مشتری

مشتری با لینک token وضعیت، حجم و انقضا را می‌بیند.
