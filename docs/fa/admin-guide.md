# راهنمای مدیر (Admin)

## ورود

`/admin/login`

## وظایف اصلی

| بخش | توضیح |
|-----|--------|
| نمایندگان | ایجاد/ویرایش Agent |
| سرورها | MikroTik، Sanaei/3x-ui، PasarGuard، Remnawave — تست اتصال و سینک |
| بسته‌ها | قیمت پایه و کمیسیون پیش‌فرض |
| اکانت‌ها | ایجاد اکانت برای فروشنده |
| درخواست شارژ | تأیید شارژ نمایندگان |
| گزارش‌ها | فروش روزانه/ماهانه |
| تنظیمات | نام سایت، SMTP |

## کمیسیون (مثال ۱۰۰۰ تومان)

- agent_rate = 50%، seller_rate = 2%
- سود مدیر: 500 تومان
- سهم نماینده: +20 تومان
- هزینه فروشنده: −480 تومان

## کیف پول مدیر

کیف پول مدیر نامحدود است؛ تراکنش‌ها فقط برای حسابداری ثبت می‌شوند.

## پنل Remnawave

راه‌اندازی سرور و پکیج: [remnawave-shahpanel.md](./remnawave-shahpanel.md) — مستندات API: [remnawave-api.md](./remnawave-api.md).

## امنیت

- اعتبار سرورها رمزنگاری شده در DB
- فقط Admin به credentials سرور دسترسی دارد
- لاگ فعالیت در `activity_logs`
